Из-за существования IE6 и большого количества браузеров с разной поддержкой веб-стандартов для написания кода JS был использован jQuery, он позволяет написать скрипты, которые будут работать одинаково вне зависимости от браузера. Также был использован Magnific Popup — это адаптивный лайтбокс и диалоговый скрипт, ориентированный на производительность и обеспечивающий наилучшее взаимодействие с пользователем на любом устройстве.
Возможность создания удобного Web-интерфейса дает фреймворк AJAX. При его использовании нет необходимости обновлять каждый раз всю страницу, так как обновляется только ее конкретная часть. Это намного удобнее, так как не приходится долго ждать, и позволяет пользователям не тратить трафик. С его помощью можно организовать подгрузку постов и переключение форм в панели администратора.
Для реализации небольших появляющихся боксов с каким-либо контентом использован плагин JavaScript – Popper.js с максимум возможностей для динамических всплывающих подсказок на сайте. Плагин самостоятельно определяет позиционирование элементов и благодарю своему алгоритму высчитывает координаты, где будет появляться подсказка. 
В меню навигации, ссылках социальных сетей и остальных иконках, а также шрифтах удобен будет Font-Awesome – основанный на CSS и Less.
С помощью плагина Owl.Carousel была реализована адаптивная карусель последних новостей и проектов.
